## Install via GitHub Desktop
1. Extract the GitHub update ZIP.
2. Replace the matching individual files `src/styles.css` and `package.json` in your cloned repository.
3. Add the two `.jpg` images to `public/media/` in the cloned repository. Keep other images and folders.
4. In GitHub Desktop review five changes (two modified files, two image files, one release note).
5. Commit with `Portfolio v0.9.2 - Correct writing article images`, then Push origin.
6. Verify the Actions build is green before inspecting `/#/writing` and the two note pages.

The images are designed concepts with demonstration content; they are not real project screenshots or actual analytics results.
